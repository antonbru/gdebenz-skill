# Настройка скилла под себя

Скилл `gdebenz-api` собран так, чтобы его легко было адаптировать под свои привычки: другое топливо, другой радиус, с комментариями или без.

## Способ 1. Переменные окружения (самый простой)

Скрипт `nearest_stations.py` читает переменные окружения:

| Переменная | По умолчанию | Описание |
|---|---|---|
| `GB_API_FUEL` | `95` | Приоритетное топливо: `92`, `95`, `ДТ` |
| `GB_API_FALLBACK` | `92` | Запасное топливо, если основного нет нигде. Пустая строка — без fallback |
| `GB_API_RADIUS` | `5` | Радиус поиска, км |
| `GB_API_TOP_N` | `8` | Сколько станций показывать |
| `GB_API_COMMENTS` | `1` | Показывать комментарии водителей (`0` — выключить) |
| `GB_API_COMMENT_N` | `5` | Для скольких станций тянуть комментарии |

Примеры:

```bash
# Только дизель, радиус 10 км, без комментариев
GB_API_FUEL=ДТ GB_API_RADIUS=10 GB_API_COMMENTS=0 python3 skills/gdebenz-api/scripts/nearest_stations.py 55.7539 37.6208

# 92-й, радиус 3 км, комментарии только для 3 станций
GB_API_FUEL=92 GB_API_RADIUS=3 GB_API_COMMENT_N=3 python3 skills/gdebenz-api/scripts/nearest_stations.py 55.7539 37.6208
```

CLI-аргументы (`python3 nearest_stations.py <lat> <lon> [radius] [fuel]`) перекрывают переменные окружения.

### Как передать переменные агенту

- **Hermes**: пропишите в окружении процесса агента (например, в `config.yaml` → `env`), либо просто отредактируйте SKILL.md — агент следует инструкции.
- **OpenClaw / Claude Code / Cline**: переменные в `~/.openclaw/.env` / `~/.claude/settings.json` (env) / окружении IDE. Либо правка SKILL.md.

## Способ 2. Правка SKILL.md (рекомендуется для агентов)

Откройте `skills/gdebenz-api/SKILL.md`, секция **«Приоритеты (по умолчанию)»**:

```markdown
- **95-й бензин — приоритет.** Показывать станции, где `fuels_now` содержит `95`.
- Если **совсем нет** станций с 95-м — на самый край показать с 92-м (пометка «только 92»).
- **Комментарии водителей важны**: ...
```

Поменяйте под себя — агент прочитает скилл и будет следовать новым правилам. Например, «всегда 92-й», «радиус 3 км», «комментарии не нужны» — просто перепишите эти строки.

## Способ 3. config.example.yaml

В корне репозитория есть [config.example.yaml](../config.example.yaml) — шаблон с комментариями. Можете держать его в своём проекте как документацию к настройкам.

## Смена языка ответа

Пока поддерживается русский (`ru`), в `config.example.yaml` поле `lang` зарезервировано. Для английского — правьте текст вывода в `nearest_stations.py` (функции `print_rows`, `main`) или дайте агенту инструкцию «отвечай на английском» в SKILL.md.

## Советы

- Радиус больше 10 км в крупных городах возвращает 100+ станций — скрипт всё равно покажет только топ-N.
- Данные краудсорсинговые: для критичных решений проверяйте свежесть отметки (`t` у цены, даты комментариев).
- Статус `null` ≠ «нет бензина» — это «нет отметки». Показывайте его как «—».
